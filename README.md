# ha-addon-egd-dlms

Home Assistant add-on repository — čtečka elektroměru EG.D (DLMS/COSEM přes RS485
HAN port) → MQTT Discovery. Postaveno nad [lhubac/egd-dlms](https://github.com/lhubac/egd-dlms).

## Přidání do Home Assistant

1. **Nastavení → Doplňky → Obchod s doplňky → ⋮ (vpravo nahoře) → Repozitáře**
2. Přidej: `https://github.com/blesk89/ha-addon-egd-dlms`
3. Add-on "EGD DLMS Elektroměr" se objeví v obchodě, nainstaluj a nakonfiguruj.

Detail add-onu a jeho nastavení: [`egd_dlms/README.md`](egd_dlms/README.md).
